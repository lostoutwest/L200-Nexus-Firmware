# Pinout

## GPIO Assignments

| Function       | Pin | Description     |
| :---           | :---: | :---            |
| Lock           | GPIO16 | Lock Relay      |
| Unlock         | GPIO17 | Unlock Relay    |
| Ignition       | GPIO18 | Ignition Relay  |
| Starter        | GPIO19 | Starter Relay   |
| Headlights     | GPIO21 | Headlights Relay|
| RGB            | GPIO23 | RGB LED Strip   |
